# Scratch-Like

Application de dessin inspirée de Scratch. Ce projet permet à l'utilisateur de créer et d'exécuter un programme de dessin sur un Canvas à l'aide d'actions configurables.

Projet réalisé dans un cadre académique.

## Fonctionnement de l'application

L'interface est divisée en trois zones principales :
- **À gauche :** Le catalogue des actions disponibles.
- **Au centre :** La liste des actions du programme. L'utilisateur peut ajouter, déplacer, supprimer ou dupliquer des actions (ainsi que gérer des boucles et des variables).
- **À droite :** La zone d'exécution pour lancer le programme, voir le dessin s'afficher sur le Canvas, et suivre l'état de la position et des variables.

## Fonctionnalités principales

- Création et modification de programmes pas à pas (ajout, suppression, réorganisation des actions).
- Utilisation de variables et de boucles.
- Exécution du programme avec affichage du résultat et gestion des erreurs de base.

## Stack technique

- Langage : Java
- Interface graphique : JavaFX
- Gestion de version : Git

## Installation et Lancement

1. Cloner le projet et l'ouvrir dans un IDE Java.
2. S'assurer que le JDK et JavaFX sont correctement configurés.
3. Lancer la classe principale de l'application : App.
